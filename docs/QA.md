## 3. Граничные случаи — здесь обычно живут баги

- [ ] Черновик короче 20 символов → понятная ошибка в UI, не белый экран.
- [ ] Ответить только на часть вопросов → карточка всё равно собирается.
- [ ] Стереть название и подтвердить → понятная ошибка.
- [ ] Отклик со ссылкой «abc» → ошибка валидации в UI.
- [ ] Двойной клик по «Подтвердить» и «Опубликовать» → нет дублей (кнопки блокируются на время запроса).
- [ ] F5 посреди конструктора → нет белого экрана.
- [ ] Остановить backend → фронт показывает ошибку, не падает.
- [ ] Неверный `OPENAI_API_KEY` → за пару секунд `ai_mode` «заглушка», сценарий проходит. Потом вернуть ключ.
- [ ] Фильтр по отрасли без задач → пустое состояние с текстом.
- [ ] F12 → Console: нет красных ошибок на всём сценарии.
