## Найденные проблемы

### 1. Guard не гарантирует отсутствие выдуманных фактов

`backend/app/ai/guard.py:56` проверяет происхождение цитаты и наличие чисел в исходнике, но не связь значения поля с цитатой. Воспроизведение без внешнего API:

```python
from app.ai.guard import apply_guard
from app.ai.schemas import FieldOut

source = "Мы сеть кофеен в Алматы. Продажи в будни падают."
values, evidence, removed = apply_guard({
    "constraints": FieldOut(
        value="Используем Kubernetes и PostgreSQL, доступ без NDA",
        evidence="Продажи в будни падают",
    ),
}, source)
# Сейчас выдуманное constraints принято, removed пуст.
```

Это противоречит требованию кейса §5. Существующие тесты проходят, потому что не покрывают этот случай. Нужна доработка владельцем AI-зоны: неподтверждённое значение отклонять или сохранять только подтверждённый фрагмент, с регрессионным тестом. Проверка доли совпавших слов сама по себе не доказывает сохранение смысла и отрицаний.

### 2. Небезопасное содержимое AI-логов

`backend/app/ai/client.py:93` пишет полный текст исключения провайдера, а строка 98 — фрагмент ошибки валидации. Ответ провайдера может содержать данные запроса или фрагмент ключа. Локальный тест с синтетическим исключением подтвердил, что его приватный маркер попадает в лог. Утечка настоящего ключа этим тестом не утверждается.

Нужно логировать только безопасные метаданные: провайдер, тип ошибки, HTTP-статус и номер попытки, без тела ответа, входных данных и текста исключения. Разрешение на изменение чужой зоны запрошено. В реальных пробных запросах журналирование было отключено, наружу выведены только статус и тип ошибки.

### 3. README не соответствует результатам сдачи

Корневой `README.md` содержит только название репозитория и одну строку. По кейсу §10 нужны запуск, архитектура, формула, правила каталога и тестовые сценарии. Материалы в AGENTS.md, `docs/readme_ai.md` и `docs/demo_script.md` есть, но README для жюри их не объединяет. Это задача L5 владельца корневой документации.

Новые задачи проходят пересчёт корректно. Старые данные не переписаны: бизнесу нужно открыть карточки и вручную подтвердить их заново. Не запускать `reset_db` на основной БД без согласия — это удалит пользовательские задачи. Точные демонстрационные места #4 → #2 требуют подготовленного набора, а не произвольной накопленной БД.

### 5. Зависимости и резервный провайдер

`npm audit` сообщает GHSA-wrjc-x8rr-h8h6 и GHSA-337j-9hxr-rhxg для React Router. Предложенное исправление — переход на `react-router-dom` 7.18.4 (major); автоматически не выполнялся. Это клиентское SPA без SSR, внутренние маршруты формируются приложением, поэтому наличие пакета не доказывает эксплуатацию всех указанных сценариев. Перед внешним развёртыванием нужен согласованный upgrade и повторный прогон.

NVIDIA возвращает HTTP 403. Настройки модели и ключа сохранены именно как предоставлены; другая модель без согласования не подставлялась. Работает основной OpenAI и локальный fallback, но исправность цепочки из двух внешних провайдеров не подтверждена.

## Настройки и безопасность

- Настройки находятся только в `backend/.env`. Backend уже загружает этот файл относительно `app/db.py`, независимо от текущей папки.
- В `.gitignore` исключены `.env` и `.env.*`; `.env.example` остаётся доступен для коммита. Сам `.env` не отслеживается Git.
- Ключи не добавлены во frontend и не имеют префикса `VITE_`. Значения секретов не включены в отчёт.
- Поскольку оба ключа были отправлены в чат, их нужно отозвать у провайдеров и заменить непосредственно в локальном файле, не отправляя новые ключи в переписку.
- После смены `.env` перезапустить backend: уже запущенный процесс не перечитывает окружение автоматически.
- Сервисы предназначены для локального демо: переключатель ролей не является авторизацией, публикация приложения в интернет с платными ключами без защиты недопустима.

## Локальный запуск

Два терминала из корня репозитория, при уже установленных зависимостях:

```powershell
cd backend
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

```powershell
cd frontend
npm.cmd run dev
```

Интерфейс: http://localhost:5173. API: http://127.0.0.1:8000/docs. Vite проксирует `/api` на порт 8000. Для полностью локального демо без внешних запросов указать `AI_MODE=stub` в `backend/.env` и перезапустить backend.
